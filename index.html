탐색과 추론 시뮬레이터

이 사이트는 부산동성고등학교 「인공지능 기초」 수업에서 배우는 탐색 알고리즘과 추론 과정을 직접 실행해보며 눈으로 확인할 수 있도록 만든 인터랙티브 학습 도구입니다.

깊이 우선 탐색(DFS), 너비 우선 탐색(BFS), 언덕 등반 탐색(Hill Climbing), 최상 우선 탐색(Best-First Search), A* 알고리즘이 실제로 탐색하는 과정을 단계별로 시각화하고, 논리적 추론 문제를 직접 풀어보는 시뮬레이터를 순서대로 제공할 예정입니다.

인공지능의 계층 구조

인공지능 Artificial Intelligence
머신러닝 Machine Learning
딥러닝 Deep Learning
인공지능 (AI)
사람처럼 인식·추론·학습·판단하도록 만든 기술 전체를 가리키는 가장 큰 범주입니다. 이 사이트가 다루는 탐색·추론 알고리즘도 인공지능의 한 갈래입니다.
머신러닝 (ML)
규칙을 직접 입력하지 않고, 데이터로부터 스스로 패턴을 학습해 문제를 해결하는 인공지능의 하위 분야입니다.
딥러닝 (DL)
인공신경망을 여러 층으로 쌓아 복잡한 데이터의 특징을 스스로 추출·학습하는 머신러닝의 하위 분야입니다.

탐색 트리

Search Tree

문제를 하나씩 풀어나가는 과정을 나무(트리) 모양으로 펼쳐본 것이 탐색 트리입니다. 각 노드는 하나의 상태(state)를, 가지는 그 상태에서 할 수 있는 선택을 나타냅니다. 아래에서 문제를 하나씩 열어 규칙을 확인하고 탐색 트리를 만들어 보세요.

문제 & 규칙

  • 4×4 체스판에 퀸(Queen) 4개를 서로 공격하지 못하도록 배치하는 문제입니다.
  • 퀸은 가로 · 세로 · 대각선 방향으로 몇 칸이든 이동(공격)할 수 있습니다.
  • 따라서 두 퀸이 같은 행, 같은 열, 같은 대각선 위에 있으면 안 됩니다.
  • 빈 보드가 초기 상태이고, 이 조건을 모두 만족하며 퀸 4개를 다 놓은 상태가 목표 상태입니다.

문제 & 규칙

  • 5×5 체스판에 퀸(Queen) 5개를 서로 공격하지 못하도록 배치하는 문제입니다.
  • 퀸은 가로 · 세로 · 대각선 방향으로 몇 칸이든 이동(공격)할 수 있습니다.
  • 따라서 두 퀸이 같은 행, 같은 열, 같은 대각선 위에 있으면 안 됩니다.
  • 빈 보드가 초기 상태이고, 이 조건을 모두 만족하며 퀸 5개를 다 놓은 상태가 목표 상태입니다. (서로 다른 목표 상태가 4-Queens보다 훨씬 많습니다.)

깊이 우선 탐색

Depth-First Search (DFS)

한 방향으로 갈 수 있는 만큼 최대한 깊이 들어간 뒤, 더 이상 갈 곳이 없으면 이전 갈림길로 되돌아와 다른 길을 탐색하는 방식입니다. 아래에서 문제를 하나씩 열어 직접 탐색 순서를 클릭해 보세요.

문제 & 규칙

  • 트리에서 깊이 우선 탐색(DFS) 순서대로 노드를 클릭해 보세요. 클릭한 순서가 아래에 "A → B → …" 형태로 표시됩니다.
  • 분기점에서는 왼쪽(알파벳이 앞선 노드)부터 먼저 내려갑니다. 더 갈 곳이 없으면 바로 위 분기점으로 되돌아가 다음 가지를 탐색합니다.
  • 주황색으로 표시된 노드가 목표 상태입니다. 목표 상태까지 도달하는 순서를 모두 클릭하면 자동으로 채점됩니다.

문제 & 규칙

  • 농부가 양, 늑대, 양배추를 배에 실어 강 건너로 옮기려 합니다. 배는 한 번에 농부 외에 한 가지만 태울 수 있습니다.
  • 농부가 없는 곳에 양과 늑대만남으면 늑대가 양을 잡아먹습니다.
  • 농부가 없는 곳에 양과 양배추만 남으면 양이 양배추를 먹어버립니다.
  • 넷 모두 강 건너편으로 무사히 옮기면 목표 상태입니다.
